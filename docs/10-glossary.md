# 用語集（ゲームの言葉 ⇔ Raft の言葉）

| ゲームの言葉 | Raft / 実装の言葉 | 説明 |
|---|---|---|
| 離島Raft共和国 | Raft クラスタ | 島（ノード）の集まり |
| 島 | ノード（`RawNode`） | 1 つの島 = 1 つの Raft ノード。ID は 1 から |
| 代表（👑） | Leader | 記録の提案と複製を取り仕切る島 |
| 一般の島 | Follower | 代表からの記録を受け取って保存する島 |
| 立候補の相談中 | PreCandidate | 選挙を始めてよいか、他の島に相談している状態（PreVote） |
| 立候補中（📣） | Candidate | 正式に立候補して票を集めている状態 |
| 代表の任期 | Term | 選挙のたびに 1 増える番号。古い任期の手紙は無視される |
| 共和国の台帳 | Raft のログ ＋ 状態機械 | 全島で同じ順番に記録される決定事項 |
| 記録 | ログのエントリ | 台帳の 1 行（`index`・`term`・内容） |
| 共和国で確定 | Commit | 過半数の島がその記録を持ったこと |
| 確定（依頼元に届いた） | Apply（依頼元のノード） | 依頼元の島が、確定した記録を自分の台帳に反映したこと |
| 過半数 | Quorum | 3 島なら 2、5 島なら 3、7 島なら 4 |
| 手紙 | メッセージ（`raftpb.Message`） | 島から島への通信。ゲームでは船で運ぶ |
| お元気ですか？ | `MsgHeartbeat` | 代表の定期便 |
| 元気です！ | `MsgHeartbeatResp` | 定期便への返事 |
| この内容を記録して！ / 記録の確認 | `MsgApp` | 記録の複製 |
| 記録したよ！ / 記録が合わないよ… | `MsgAppResp`（`Reject`） | 複製への返事 |
| 立候補してもいいかな？ | `MsgPreVote` / `MsgPreVoteResp` | 選挙の前の相談とその返事 |
| 代表に立候補します！ / あなたに投票します！ | `MsgVote` / `MsgVoteResp` | 投票の依頼とその返事 |
| 住民の依頼書 | （アプリの手紙）| Follower の島から代表の島へ依頼を届ける。Raft の `MsgProp` の転送の代わり（ADR-0008） |
| 港 | 送信キュー | Raft が出力したメッセージが、配達を待つ場所 |
| フェリー | Transport | メッセージを運ぶもの。この作品では、ネットワークそのもの |
| 嵐 | ネットワーク分断（Network Partition） | 航路が通れず、島どうしが連絡できない状態 |
| 定期便が途切れる | Election Timeout | 代表から一定時間連絡がないと、島は立候補を始める |
| 孤立した代表が退く | CheckQuorum | 代表が過半数と連絡できないと、自分から Follower に戻る |
| 古い手紙 | 古い Term のメッセージ | 届いても、受け取った島は無視する |
| 漂流瓶 | メッセージの遅延・重複 | 過去の手紙の複製が届く。Raft はこれに耐える |
| 開会式 | 初回の選挙（ブートストラップ） | ゲーム開始時に、船を使わずに最初の代表を決める |
| 役場 | アプリケーション層の依頼の処理 | 依頼を代表へ転送し、届かなければ再送する |
| ゲーム内時間 | `SimTime`（仮想時間） | シミュレーションの時計。実時間とは別 |
| シード | 乱数のシード | 同じシードと同じ操作なら、同じ展開になる |
| 入力ログ | — | リプレイのための操作の記録 |
| トレース | — | ゲーム中に起きた出来事（ドメインイベント）の記録 |
| エンジニアモード | — | Raft の内部状態を重ねて表示するモード |
