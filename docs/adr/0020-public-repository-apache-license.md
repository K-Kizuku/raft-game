# ADR-0020: リポジトリを公開し、ライセンスは Apache-2.0 にする

- 状態: Accepted
- 日付: 2026-11-06
- 決めた人: プロダクトオーナー（Q-12）
- 関連: NFR-13、ADR-0005、ADR-0013、[判断の記録 Q-12](../09-assumptions-and-open-questions.md#q-12)

## 背景

このリポジトリには、ライセンスの異なるものが混ざる。

| 含まれるもの | ライセンス・条件 |
|---|---|
| 自分たちのコード | （この ADR で決める） |
| etcd-io/raft（改変して同梱） | Apache License 2.0 |
| 国交省のオープンデータ（元の CSV と加工したもの） | 政府標準利用規約（第 2.0 版） |
| 画像生成 AI で作った素材 | 使う生成サービスの利用規約による |

公開すると、審査員や見に来た人がコードを読めるので、「本物の Raft が動いている」ことを示す材料になる。

## 検討した選択肢

| 案 | 長所 | 短所 |
|---|---|---|
| Apache-2.0 | 自由に使える。特許に関する取り決めがある。同梱する etcd-io/raft と同じなので、表示をそろえやすい | MIT より文面が長い |
| MIT | 最も短く分かりやすい | 特許の取り決めがない |
| ライセンスなし | — | 他の人が法的に再利用できない |

## 決定

- リポジトリは**公開**する
- 自分たちのコードのライセンスは **Apache-2.0**
- ルートに `LICENSE`（Apache-2.0 の本文）と `NOTICE` を置く。`NOTICE` には次を書く
  - etcd-io/raft を同梱し、乱数源を注入する変更を加えたこと（詳細は `server/third_party/etcd-raft/PATCHES.md`）
  - 国交省のオープンデータを加工して使っていること（出典と利用規約）
  - 画像生成 AI で作った素材と、使ったサービス

## 結果

- 良いこと: 誰でも読めて、再利用もできる
- 悪いこと: シークレットを誤ってコミットしないよう、より注意が必要（`.gitignore`、CI のシークレットの検査）

## 見直すきっかけ

- 画像生成 AI のサービスの利用規約が、公開・再配布を制限しているとき（その素材だけ別のライセンスにするか、差し替える）
